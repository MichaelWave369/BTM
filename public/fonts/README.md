# Bundled typefaces

Oxanium by Severin Meyer and Racing Sans One by Impallari Type are redistributed under their included SIL Open Font License 1.1 files. The original, unmodified TTF files ship with the game; the browser makes no font-service request.

Sources (retrieved 2026-10-27):
- https://github.com/google/fonts/tree/main/ofl/oxanium
- https://github.com/google/fonts/tree/main/ofl/racingsansone

All SVG artwork, interface icons and Canvas interface illustrations in this release are original code-native work for Michael Wave & Ori. The supplied concept image guided the visual direction; it is not included or rendered as the interface.
