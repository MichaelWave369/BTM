# Quest Touch / Cybernetic equipment

Open the HTTPS game in Quest Browser, choose **Immersive VR**, then use the existing title/mission menu to continue or start. **VR Arcade** retains the world-anchored screen presentation. No hand-only tracking is required or implemented.

| Control | Immersive action |
| --- | --- |
| Head / body | Independent look, lean, physical crouch and collision-safe room movement |
| Left stick | Move/strafe; head-relative by default, optional left-controller reference |
| Right stick horizontal | Smooth turn by default; optional snap turn (15°, 30°, 45°) in Settings |
| Right stick up/down | No weapon cycling; select weapons deliberately through the left-wrist Arsenal |
| Right trigger | Fire; select a pointed wrist/menu control |
| Left trigger hold/release | Charge/release existing alternate shot using energy |
| Right grip / A | Use nearby pointed door, captive, relay or archive; extraction keeps original gates |
| Left grip | Ori scan/stun |
| B / X / Y | Dash Bash or shield / reload / vision (Legacy: dodge / vent) |
| Left stick click, held | Sprint |
| Right stick click | Pause/resume |
| Left watch OPEN MENU (right ray + trigger) | Opens/closes the nearby Fieldlink panel while left-stick movement continues |
| Pause / settings | Checkpoints, comfort/graphics, manual, recenter and safe XR exit |

Turn the left forearm toward your eyes, point your right controller at the small watch's OPEN MENU button, and squeeze RIGHT TRIGGER. The larger panel opens directly above the cuff. Lowering the hand closes it. The laser and gold outline indicate selection. Movement and the world clock continue while Fieldlink is open. Fieldlink reserves firing, charging, stick turning and combat shortcuts until you close it, point away and release those controls. Press the right stick or select PAUSE to stop solo gameplay.

The watch-face OPEN MENU button requires the watch to be facing you, within reach and visible. Old saved automatic preferences migrate to button-only. Equipment settings offer 240–380mm width, projection offset, facing sensitivity, HUD visibility, brightness, three glove finishes, ±40mm XYZ weapon grip calibration and interface motion. The large display follows the cuff. Near-face or invalid wrist placement hides it.

Gloves use ordinary controller grip poses. The weapon follows grip position and the preferred pointing ray; model and muzzle share the existing collision/reach safeguard. A cyan focus ring marks usable world objects; amber marks blocked extraction/key requirements. Hidden-wall highlights require existing vision. Locked weapons remain unavailable. Map markers appear only in discovered cells.

Comfort HUD subtitles are the default. Speaker labels, wrapped text, portrait and signal waveform identify the channel. Subtitle size and duration are adjustable. **Ori Spatial** appears near Ori only within clear forward view and falls back when behind, distant, occluded or overlapping the wrist/sight. Communication remains available when wrist HUD visibility is off; menus hide it.

Settings retain seated/standing heights, custom eye height, recenter, head/controller movement, movement speed, snap choices and optional aim line. **Smooth turn speed** affects only smooth turn. **Vignette strength** changes the movement comfort mask independently of its on/off switch. Collision fade remains protective. Start with snap, moderate movement speed and vignette, then adjust to comfort. Reduced motion steadies decorative terminal/Ori animations. There is no artificial headset camera shake.

Quality changes wall-fixture counts, ring detail, particle/trail budgets and distance immediately. Render scale applies on the next XR entry. Optional controller vibration and positional sound retain their existing settings and behavior. Generic xr-standard controllers retain trigger/grip/sticks; wrist utilities provide actions whose face buttons are not standardized. Face labels above apply to supported Quest profiles.

Recenter after changing posture or play position. A tracking reset, missing right hand, removed controller or hidden headset pauses input. Exit preserves the game paused in Classic. The existing immersive title/pause architecture remains; a dedicated staging environment, teleport and direct touch are deferred. See [hardware acceptance](equipment/quest3-acceptance.md).

## Calibration Vault debug aim check

In **Immersive Settings**, enable **VR Diagnostics** and enter the **Calibration Vault**. The visible long cyan firing ray follows the actual tracked hitscan. A pale mark indicates a predicted hittable target and amber indicates a wall/floor/range obstruction. This is a candidate diagnostic, not an aim correction or physical headset certification. The projectile-based Φ Pulse Rifle retains its normal short guide. See [Quest aiming acceptance](quest3-aim-diagnostics.md).
