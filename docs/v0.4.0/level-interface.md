# Level geometry interface — mwori.level/1.0

`createLevel(index)` remains the authoritative map. `buildLevelGeometry(level)` derives static native WebGL meshes; `WorldScene` reads live doors/enemies/items/objectives. No VR-only map or enemy simulation is maintained. `exportLevelIR(level, definition)` exports a versioned description for future packaging, not a new save format or an untrusted-map importer. `sector-01.level.json` is generated by that exact function.

| Field | Meaning |
| --- | --- |
| `schemaVersion` | `mwori.level/1.0`; incompatible changes require a new schema major |
| `units` | 1.6 meters/tile, ceiling 1.7 tiles / 2.72m |
| Coordinates | Game x/y/height → world X/Z/Y, multiplied by 1.6 |
| `grid` | Shared dimensions and copied tile cells |
| Cell 0 | Walkable floor with ceiling |
| Cells 1–3 | Solid walls/pillars and owned material |
| Cells 4/5/6 | Door / gold-key door / secret wall |
| `rooms`, `corridors`, `regions` | Authored rectangles and named bounds |
| `surfaces` | Stable owned procedural atlas material IDs |
| `doors` | Cell ID/type/axis/material; animation stays authoritative in core |
| `entities` | Original enemy/item/captive spawns plus decorative props |
| `objectives`, `secrets` | Relays, key, extraction, secret-door IDs |
| `collision` | Shared grid; .2-tile player radius; .84 door passage threshold |

Static chunks cover 8×8 tiles with exposed wall faces and floor/ceiling quads. Each triangle vertex is XYZ/UV/RGBA: nine floats, 36 bytes. One 1024² atlas uses inset 64px cells of existing/owned procedural art. Door meshes rise with the same `door.open` value used by collision. Pillars remain true grid solids; decorative pods/consoles/speakers/lamps retain their original nonblocking behavior.

`ImmersiveRig` sweeps physical X/Z motion through the same `moveBody` as Classic, clamps the camera on collision, calibrates eye height while preserving crouch delta and clips the hand/muzzle at walls/floor/ceiling and .85m reach. Head rotation never assigns body angle or weapon aim. Stereo VP is `nativeProjection * nativeEyeInverse * rigInverse`.

`stepImmersive` runs `Game.update` once. A post-movement hook updates the tracked pose before enemy/projectile logic, then actions/firing use the finalized muzzle. Six common weapon definitions retain damage/cost/cooldown/upgrade rules. `setCombatPose({head,aim:{origin:{x,y,height},direction:{x,y,z}}})` supplies transient 3D combat input; XR state is excluded from v1 saves. Classic uses the original horizontal branch when no combat pose exists.

Future PixelForgeStudio exports could write this IR and owned-asset references; Domistika could validate/package it; BackyardProductionCompany could bundle the static game/asset package. Add schema/bounds/ID/unit/asset/reachability validation and an importer in a separate milestone. No external project, editor, account, service or runtime engine integration was added here.

API references consulted: https://www.w3.org/TR/webxr/ and https://www.w3.org/TR/webxr-gamepads-module-1/ .
